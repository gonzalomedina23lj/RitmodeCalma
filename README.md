# Ritmo de Calma — versión modernizada

Esta versión está pensada para GitHub Pages y no necesita framework ni servidor.

## Archivos

- `index.html` — estructura y contenido.
- `style.css` — diseño responsive, animaciones y efectos.
- `script.js` — navegación móvil, scroll reveal, barra de progreso, parallax y pausa guiada.

## Cómo publicarla

1. Reemplazá el `index.html`, `style.css` y `script.js` actuales por estos archivos.
2. Hacé commit/push al repositorio.
3. GitHub Pages debería servir automáticamente el sitio si ya estaba configurado.

## Importante sobre la imagen

La foto de la sección Filosofía está cargada desde Unsplash mediante una URL externa. Si querés que el sitio sea completamente independiente de servicios externos, descargá una imagen propia y reemplazá el `src` de esa imagen por algo como `assets/meditacion.jpg`.

## Importante sobre el formulario/audio

Esta versión no inventa un backend de correo ni un archivo de audio que todavía no existe. La "Pausa de 60 segundos" funciona directamente en el navegador con JavaScript.

Para una versión comercial, recomiendo conectar el CTA principal a una landing de venta o checkout y el formulario de email a un servicio de email marketing.
